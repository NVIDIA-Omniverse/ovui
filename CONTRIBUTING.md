# Contributing

Thank you for your interest in omni-ui (ovui).

This repository is a public mirror of an internal NVIDIA project. We are
**not currently accepting external pull requests or code contributions**.
Source is published for transparency and reuse under the license stated
in [README.md](README.md), but development happens in NVIDIA's internal
tree and is mirrored here.

## What you can do

- **Bug reports and feature requests** are welcome via the
  [GitHub issue tracker](https://github.com/NVIDIA-Omniverse/ovui/issues).
  Please include a minimal reproduction, the backend you're using
  (GLFW / Vulkan headless / EGL headless), and your platform.
- **Questions and discussion** can also go through the issue tracker.

## If this policy changes

If we open the project to external contributions in the future, this
file will be updated with the contribution workflow (sign-off,
review process, style guide, etc.). Until then, please do not open
pull requests against this repository — they will be closed without
review.

## Contact

For questions that aren't appropriate for a public issue, contact the
maintainers listed in the repository metadata.

Do not report security vulnerabilities through public GitHub issues. See SECURITY.md for private disclosure instructions.
