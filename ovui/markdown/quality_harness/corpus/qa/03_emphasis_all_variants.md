# Inline Emphasis

Plain text baseline for comparison.

*Italic text* using single asterisks.

_Italic text_ using single underscores.

**Bold text** using double asterisks.

__Bold text__ using double underscores.

***Bold italic text*** using triple asterisks.

~~Strikethrough text~~ with double tilde.

## Inline combinations

This paragraph has **bold**, *italic*, ***bold italic***, `inline
code`, and ~~strikethrough~~ all mixed together and should render each
with a distinct visual style.

*one**two**three* — italic with a bold island in the middle.
